# CampusPrint Portal

Create a web application named 'CampusPrint' for a college Xerox and stationery ordering system. Build a clean, modern, student-friendly interface using Tailwind CSS and Lucide icons.

Include a top navigation bar with a Role Switcher toggle: 'Student Portal' and 'Shop Staff Dashboard'. Use clean card-based layouts for both views."
